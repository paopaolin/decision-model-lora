# 01 · OneJev-Data Schema 审计报告

数据源：`OmniJev/OneJev-Data`（HF 数据集，公开，免申请，全量 94,807 行 / 17.74GB）
审计样本：前 3 个 parquet 分片（2.8GB），**15,852 行，覆盖全量 16.7%**
审计日期：2026-10-27
工具：`onejev_audit.py`（只读必要列，不加载 images 二进制；media 判断已修正 JSON 字符串解析）

---

## 一、字段定义

| 字段 | 实际类型 | 含义 | 训练器是否使用 |
|---|---|---|---|
| `id` | str | 全局唯一样本 id | 否（仅追踪；**发现 2 条重复**） |
| `source` | str | 原始数据集来源 | 是（记入 run） |
| `task` | str | 任务类型 | 是（记入 run） |
| `split` | str | 数据划分（本批全部 `train`） | 是（`--split` 过滤） |
| `license` | str | **逐条**标注，非统一值 | 否（筛选时用） |
| `state` | str（JSON 序列化内容） | 模型可见的判断材料 | 是 |
| `question` | **JSON 字符串** | 题目定义 | 是 |
| `target` | **JSON 字符串** | 选项→概率目标分布 | 是 |
| `media` | None 或 str | 图片引用（JSON） | 仅 multimodal 模式 |
| `meta` | str（JSON）或 None | 元数据，含 `judge` | 否（筛选时用） |
| `images` | 二进制 | 实际图像数据 | 仅 multimodal 模式 |

## 二、题型与选项

- 题型：`choice` 7,533（47.5%）／`noul` 5,865（37.0%）／`score` 2,454（15.5%）
- 选项数：2 个选项 6,390 条为大头，但长尾延伸到 47、50、101、196、200、219 个选项
- 对照 JevBench public-231 选项数 2–6：训练分布若不按选项数过滤，与评测分布脱节

## 三、target 形态

| 形态 | 条数 | 占比 |
|---|---:|---:|
| 硬标签（近 one-hot） | 14,153 | 89.3% |
| 软分布 | 1,699 | 10.7% |

## 四、标签验证方式（`meta.judge`，选择数据时的重要依据）

| judge | 条数 | 占比 | 可信度排序 |
|---|---:|---:|---|
| `dataset_label` | 5,307 | 33.5% | 高（原数据集自带） |
| `program` | 3,682 | 23.2% | **最高**（程序核算） |
| `recorded_action` | 3,366 | 21.2% | 高（真实轨迹记录） |
| `llm:Qwen3.5-27B distill` | 1,017 | 6.4% | 低（蒸馏标签） |
| `human` | 839 | 5.3% | 高 |
| `llm:deepseek-v4.1-flash x3` | 810 | 5.1% | 低 |
| `null` | 543 | 3.4% | 未知 |
| 其他 LLM 来源 | ~274 | 1.7% | 低 |

**约 13% 的标签来自 LLM 蒸馏。** 第一轮训练建议优先用 program / dataset_label / recorded_action / human 的样本，LLM 标签放后续或排除。

## 五、长度

state 字符长度：p50 467、p90 20,880、p95 36,859、max 51,840；≤4,000 字符的占 76.4%。

对照 JevBench（p50 70、max 14,986）：OneJev-Data 长尾重得多。训练 `max_len=4096`（token）时按 3.5 字符/token 估算，约有两成样本被丢弃。

## 六、modality

| media | 条数 | 占比 |
|---|---:|---:|
| 纯文本可用（含 `'[]'` 空引用） | 4,921 | **31.0%** |
| 有图片引用 | 10,931 | **69.0%** |

修正解析逻辑后数字基本不变，"近七成依赖图像"成立。**纯文本池子约为表面的三成。**

## 七、质量

| 检查项 | 结果 |
|---|---|
| 重复 id | **2**（3 分片内） |
| 缺失 state/question/target | 0 |
| 空 state | 0 |

## 八、结论

OneJev-Data 是候选池，不是即用训练集。进入训练前必须过四道筛：

1. **格式转换**：`question`/`target`/`media`/`meta` 全是 JSON 字符串，训练器期望对象（见 09 号报告）；
2. **模态过滤**：排除 media 非空样本（69.0%）；
3. **许可过滤**：逐条 license（见 05 号）；
4. **长度与选项数过滤**：对齐评测分布。

再叠加 `judge` 筛选（优先程序与人工验证标签），可用子集的构成建议见 10 号报告。
